# Pawplans

Планер для девушек: календарь на месяц, план дня, отметки о выполнении. Работает как приложение на телефоне и компьютере, в том числе без интернета.

Сайт обычный, без сборки: `index.html`, `style.css`, `app.js`, `corgi.js`, `sw.js`, `manifest.webmanifest` и папка `icons`.

## Запуск у себя

```
python -m http.server 5173
```

и открыть http://localhost:5173

## Публикация на GitHub Pages

1. Создать на GitHub новый репозиторий (например `pawplans`).
2. Загрузить в него все файлы этой папки (включая `icons` и пустой файл `.nojekyll`).
3. В репозитории: Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
4. Через минуту-две сайт будет по адресу `https://ИМЯ.github.io/pawplans/`.

## Установка на телефон

- iPhone (Safari): «Поделиться» → «На экран «Домой»».
- Android (Chrome): меню ⋮ → «Установить приложение» или «Добавить на главный экран».

После первого открытия по https приложение сохраняется в память телефона и дальше открывается без интернета.

## Обновление

Когда меняешь файлы и выкладываешь новую версию, увеличь номер в `sw.js` (`const CACHE = 'pawplans-v2'` и так далее). Тогда телефоны скачают свежую версию, как только появится интернет.
